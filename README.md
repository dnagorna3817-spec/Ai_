# AI Workforce Prototype

High-fidelity local prototype for a CES 2027 concept: a digital workforce operating system where specialized AI employees collaborate, hand off work, and pause for human approval.

## Run locally

```bash
cd /Users/macbook/Documents/NOVA-AI-Workforce
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Demo flow

1. Enter the AI office from the product introduction.
2. Open **Prepare client for monthly close**.
3. Review the vertical AI collaboration workflow.
4. Open the decision assigned to Diana.
5. Select **Approve & Send**.
6. Return to the dashboard to see the updated count and activity.

## Technology

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide icons
- Local React state and mock data only

No backend, Supabase project, credentials, deployment, or external API is used.
